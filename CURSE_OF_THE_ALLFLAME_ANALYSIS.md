# Curse of the Allflame — Design Research Analysis (Agent C)

**Source:** GGG Live reveal VOD segment (`twitch-videos-2821565350`, Path of Exile 3.29)  
**Official naming (confirmed):** *Path of Exile: Curse of the Allflame* — patch **3.29**, launches **July 24 PDT** (forum: pathofexile.com).  
**Method:** Frame extraction via ffmpeg at trailer / league / Atlas / systems beats; visual read of stills; transcript cross-check; light web confirm of league title only.  
**Scope note:** This is **Path of Exile 1** (classic HUD, flasks, Atlas, Kirac/Kirak, Mercenaries of Trarthus). PoE2 is referenced in-stream only where Abyss modernization crossed titles.

## 1. Narrative beats / cinematic escalation design

### Trailer arc (surface → descent → curse)

Observed escalation, not “more loot banners”:

1. **Call of the depths** — fog, dark water, a lost wreck that “still draws ghostly breath.” Brand/title land after atmosphere, not before.
2. **Industrial-occult vessel** — wooden Oriathan hull fused with silver pipework and emerald Allflame glow; crane lowers a riveted **bathysphere**.
3. **Descent as rite** — lantern light punches a safe bubble into black water; bioluminescent coral / brine-rot flora; chests and corpses as archaeology.
4. **Pressure reversal** — lanterns flicker out in sequence; monsters rush the dying light; player must **escape to the bathysphere** (fail-forward tension, not a soft checkpoint).
5. **Hub return** — ship deck as lived space (charts desk, specimen jars, hatch below to Vesper’s heart).

### League story spine (spoken + shown)

| Beat | Cast / object | Design function |
|------|---------------|-----------------|
| Hook | Corsair captain **Valerie (Val)** | Needs charts + seafloor boots; player is contractor, not chosen one |
| Ship | **The Sovereign** | Re-appropriated Oriathan naval vessel; mobile league hub |
| Bound soul | **Vesper** | Pondium native; soul cursed by Allflame; body/comatose binding *is* the ship’s power plant |
| Descent tool | Bathysphere + **Allflame lanterns** | Finite light radius = playable fear; auto-fire option for speed vs manual control |
| Resource myth | **Dead man’s sulfur** from luminous coral | Fuel for Vesper *and* league crafting — story currency = system currency |
| Payoff loop | Chart → voyage board → plunder capsules → craft | Exploration, planning, extraction, and crafting share one mythic fuel |

**Cinematic lesson:** escalation is *environmental permission shrinking* (light budget → fade → escape), not UI difficulty meters. The ship is character (Sovereign / Vesper / Val), not a menu skin.

## 2. Atlas Anomaly / dynamic content escalation

**Shown and named in reveal.** After void-stone-affected maps, opening the Atlas can **manifest an anomaly** (banner example: *“ATLAS ANOMALY MANIFESTED — THE MANOR FOYER”* / Mana Foia / Manor Foyer naming in stream).

### Rules as stated

- Appear on Atlas like maps, but **no map item required** to enter.
- Often **revisit-able** until resolved (buy / exhaust offers / complete).
- **Unaffected by Atlas passive tree** and **cannot be fragment-augmented** → intentionally “run now” content, not juicing homework.
- Tied to **Atlas quadrants** → which anomalies you see can bias strategy.

### Examples shown / described

| Anomaly type | Player-facing shape |
|--------------|---------------------|
| **Mana Foia / Manor Foyer** (Kidero Pirandis) | Vendor-style gold exchange; reject → next offer costs more gold; can leave and return |
| **Reflecting Mists / Nameless Seer** | No longer random map spawns; relocated into anomaly instances; scrying moved to tradable **Scrying Orb** |
| **Heist wing sample** | Fully revealed blueprint wing + random rogue companions; **Alert Level** UI visible in footage |
| **Sacred Grove overrun** | Plants “fully taken over” — league taste without Atlas investment |
| Strongbox with strange mechanism | One-off curiosity encounter |

**Dynamic escalation pattern:** anomalies are *short, high-legibility detours* that bleed familiar league fantasy into endgame without requiring full mechanic investment. They escalate **variety and decision density**, not raw monster HP via party scaling.

## 3. Vessels / pets / companions / ships

### Ships & descent vessels (core league — high relevance)

- **The Sovereign** — full hub ship: figurehead close-ups, deck planning desk, crane, stash, below-decks craft heart.
- **Bathysphere** — spherical riveted dive pod; narrative “ticket under the waves”; also the **escape vehicle** when light dies or voyage ends (signal Val, survive until retrieval).
- **Loot capsules** — per-chart inventory-sized extraction pods Val hauls to surface (nine charts → nine extract opportunities).
- **Allflame lanterns** — portable safety vessels / light beacons; finite concurrent power from Vesper.

### Companions (gameplay, not cosmetics)

- **Mercenaries of Trarthus (core return):** duel from Act 3; wager gold for a carried item; win → temporary ally for N areas; **Warrant** to rematch later / trade the merc; **does not count as party member** (no shared life/qty/rarity tax — explicit vs old league).
- **Luminary (Scion Ascendancy):** permanently hire up to **3** mercs (1 active, 2 reserve); gear them (uniques gated by passives); Link / aura / bodyguard fantasy; Atlas + Scarab targeting; **seafloor-exclusive merc type** in rare Allflame encounters.
- Merc UI shows named agents (e.g. *Nytra, the Cyaxan Recluse*), gear doll, skill list, **TAKE ITEM / REMATCH**.

### Pets (cosmetic supporter packs only)

- **Plague Rat Pet** (Plague Supporter) — toxic green eyes/claws; MTXish companion.
- **Medi-Rhoa / Medi Roa pet** (Remidus Supporter) — pack-bearing rhoa; travel companion silhouette.

**Mythoras takeaway:** treat **ship + dive pod + light beacons** as first-class fantasy vessels; treat **permanent army companions** as a dedicated ascendancy fantasy, not default party smoothing; pets here are shop dressing, not systems.

## 4. Originals vs replicas

No classic “Replica Unique” league naming in this reveal. Closest systems:

### Ghostly outcomes (Allflame / Vesper craft)

1. Feed Vesper: **item + currency you would have used + dead man’s sulfur**.
2. Item splits into **many ghostly forms** = simulated results of applying that currency to the **original**.
3. Player keeps **one** reified outcome; others burn (Vesper “can only reify a single outcome”).
4. Cost scales with craft potency.
5. On-screen craft copy: *“Augment… Creates three ghostly copies.”* / **MAKE REAL** choice UI over multiple rolled variants of the same base.

### Dukats (rarer sea-floor currencies)

- **Kishara’s Dukat** — four ghostly copies, each keeping **one mod from the original** (base-splitting for crafting).
- **Gentiles Dukat** — attribute requirement remapping.
- **Brine Hooks Dukat** — “emissary of the gods” aspecting (teased, not fully spelled).

### Legion “vestigial” originals

Enshrouding crystals transfer power so a transformed unique keeps a **trace of the original** as a **vestigial implicit** — originality as scar, not full replica item line.

**Portable idea:** “ghost of the roll” / choose-one-from-phantoms is replica-adjacent without flooding the economy with named Replica uniques.

## 5. Skill socket / color / constellation-adjacent systems

### Socket colour rewrite (3.29 headline systems beat)

- **Base sockets no longer gate gem colour** — any colour gem into any socket.
- Explicit design goal: stop punishing upgrades and experimentation when chromatics fail.
- **Coloured sockets remain**, but rarer / craftable as **pure upside**: matching gem colour → **extra quality** on that gem.
- Chromatic Orbs still recolour; now **guarantee at least one R/G/B**.
- Links and socket *count* still constrain builds — colour friction removed, not 6-link friction.

### Adjacent systems shown

- **Luminary Ascendancy wheel** — circular node constellation UI (commander fantasy, not skill-tree sockets).
- **Voyage chart board** — 9-slot adjacency constellation: charts modify neighbors / whole voyage; edge “currents of corruption” roll voyage-wide; path/tile inventory with levels (board-game constellation, not gem constellation).
- **Pact skill gems** (casters) — self-cast identity package (Baydat, Gore, Lycia, Kittash teased); skill fantasy refresh, not socket geometry.
- Merc skill rows still show linked supports in companion UI (PoE1 gear-socket culture remains for items; colour meaning shifts).

**Constellation-adjacent for Mythoras:** prefer **adjacency boards** and **ascendancy wheels** as spatial metaphors; treat “colour as bonus quality” as a softer gate than “colour as hard lock.”

## 6. Portable Mythoras lessons vs do-not-import

### Portable (inspire, rename, own the fiction)

| Lesson | Why it travels |
|--------|----------------|
| **Light as finite permission** | Lantern budget → fade → escape is drama without explaining DPS checks |
| **Hub vessel with a bound soul** | Ship is NPC + power plant + craft station; one myth pays three systems |
| **Chart → board → voyage** | Player *authors* the run via adjacency; modifiers stack visibly |
| **Extraction capsules** | Loot tension = carrying capacity + recall survival, not only drop rates |
| **Ghost-roll craft** | Show alternate futures of one craft; keep one; burn the rest |
| **Atlas Anomalies as free detours** | Endgame variety without juicing tax; quadrant-tied discovery |
| **Temporary hire vs permanent commander** | Companion depth unlocked by class fantasy, not default for everyone |
| **Colour as reward, not lock** | If Mythoras uses affinity colours, prefer bonus over hard deny |

### Do-not-import / adapt carefully

| Pattern | Why freeze or strip |
|---------|---------------------|
| **PoE2-style difficulty smoothing** | Owner skepticism: automatic lanterns, party-tax removal, colour-gate removal can feel like sanding teeth — import *clarity*, not *comfort defaults* |
| **Mercenary as kill-bot default** | “Others can do all the killing for you” is anti-Mythoras grit unless gated hard (Luminary-only permanence helps) |
| **Gold-reject vendor loops** (Kidero) | Risk of soft pity / shopping endgame; use sparingly |
| **Alert Level / Heist slice anomalies** | Fun as rare taste; don’t make stealth-meter the core loop |
| **Supporter pets as design north star** | Cosmetics only; don’t confuse MTX pets with vessels |
| **Copying Allflame / Atlas / Trarthus names** | Steal structure, invent Mythoras myth |
| **Full PoE socket+link+chromatic stack** | Mythoras should not inherit two decades of gem bureaucracy even if colour gating softens |

## 7. Rich narrative inspiration vs PoE2 / PoE systems not to import

### Rich narrative inspiration (lean in)

- **Corsair compact:** Val’s profit cut, charts as contested treasure, undead / rival corsairs / deep horrors as chart guardians with **possession rewards** (trapped soul buff for the area).
- **Allflame as life-support curse:** Vesper dies if removed; lanterns are fragments of the same curse that keeps him alive — safety is parasitic.
- **Dead man’s sulfur:** coral grown from corrupted dead → fuel. Loot is grave-robbery with a moral texture.
- **Ship as character:** Sovereign figurehead, silvery steering apparatus, below-decks soul in “tarnished pipes and corpse-stained glass.”
- **Escape cinema:** last lanterns die; rush the bathysphere; Val races to retrieve you.
- **First Boat League swagger:** surface fantasy (deck, crane, journals) that earns the dive.

### PoE / PoE2 systems not to import into Mythoras

- **Atlas juicing stack** (void stones + tree + scarabs + fragments) as the *primary* meaning of endgame — anomalies’ “ignore the tree” is the useful exception, not the rule to copy wholesale.
- **Difficulty smoothing packages:** auto lanterns, mercs without party scaling, any-colour sockets as a *bundle* that removes friction for free. Pick at most one friction reduction and make it mythic, not QoL patch notes.
- **PoE2 Abyss/engine parity talk** as a design goal — stream cites PoE2 Abyss modernization as inspiration for PoE1 Abyss; Mythoras should not chase sequel feature parity.
- **Scion Luminary army fantasy as baseline co-op** — keep multi-companion permanence as a rare identity, not the expected play pattern.
- **Chromatic / 6-link culture** — even softened, the whole gem-socket economy is PoE-native; Mythoras should use its own constellation language if any.
- **Pact gems / vestigial Legion chase / Talisman revival** — excellent PoE retention content; not Mythoras spine.

## 9. One-line verdict for Mythoras

**Steal the Allflame’s story physics** (cursed ship-soul, finite light, authored voyage board, ghost-roll craft, free Atlas detours) **and leave PoE’s friction-removal bundle** (any-colour sockets + tax-free mercs + auto-comfort) **on the dock**—inspire atmospheres and player-authored expeditions; do not import difficulty-smoothing as default.
