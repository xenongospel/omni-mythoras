# Crafting Foundation Rethink — Agents as Protocol Tools

> **Wave 2 deliverable** (2026-07-19). Primary: Agent framework kept; Forge/Imprint soft; operations from creature/Protocol fantasy; Splice cancelled; Exploit early; Compile tempered. Skills ownership cited, not redesigned (Wave 1).
>
> Companion: `POE_CRAFTING_STEPS_RESEARCH.md` (emergent steps, weights, lock/block, 3.29 Chaos bench signal).

## 1. Executive Verdict

**Agents should be Protocol-native executable tools** — stackable, sinkable, trade-primary candidates — whose *operations* emerge from creature play (Stream coherence, species implicits, Load/role gear pressure, Squad prep), not from a PoE orb catalogue with Mythoras skins.

Keep the sold wrapper (**Agent**), the sold economy axiom (**uncapped functional barter** — `POE_CURRENCY_ECONOMY_RESEARCH.md` §1), and the sold research longevity model (**clear rules + mysterious weights** — IDEA-018 / plan sold list). Soft-reopen the interface name (**Forge Terminal**), **Imprint**, gold-as-universal, and the full ReAgent/DeAgent/enAgent MVP surface. **Cancel Splice** permanently as specified. Keep **Exploit** early; **temper Compile** (and rename it — DOC_v5 already uses Compile for Initiate→Magic).

**What “foundation” means here:** few Agent *kinds*, many emergent *steps* players invent by composing verbs + pools + locks. Depth lives in the mod/weight graph and the Squad prep fantasy — not in a 40-currency taxonomy at launch.

**Recommended MVP Agent set (summary):** Decrypt · Inscribe · Scramble · Void · Elevate · Ascend · Anchor · Exploit · (tempered) Compile-endgame · Surge/Gl!tch *(Skill Card scope per CONTEXT)* · bench floors. Defer Dual/Weighted Inscribe, Siphon/Fissure, Fracture-as-player-tool, full ReAgent/DeAgent query stack, Frame Sync/Link/Hue suite (Wave 1 may relocate), and enAgent richness.

## 4. Designer Angle — What should Agents *feel* like?

### 4.1 Foundation fantasy (creature play, not orb cosplay)

The Technician does not “alchemy an orb.” They deploy a **Protocol Agent**: a compiled instruction that rewrites how a piece of gear, a Skill Card, or (later) a Cipher resolves.

Creature-native hooks that make Agents *Mythoras*:

| Creature/Protocol lever | Crafting expression |
|-------------------------|---------------------|
| **Stream / Category** | Weighted Inscribe / bias materials (Ember Ash etc.) — coherence, not hard lock |
| **Species mod pools** | Species Inscribe + Catalyst (DOC_v3/v5) — creature identity craft |
| **Origin / tags** | Module compatibility, subtype implicits (Fang Talisman) |
| **Role (offence / tank-tradeoff / utility)** | Which slots *matter* this Sequence — not equal craft investment |
| **Load / Bench** | Gear that reduces Load cost or recovers Bench — utility craft targets |
| **Squad prep** | Pre-zone Forge session as “compile the squad,” not mid-battle fiddling |
| **Imprint Interface / Symbiotic** (CONTEXT exploration) | Distinctive slots for modules / creature-to-creature bonds |

**Innovation bar:** PoE players should recognise *verbs* (add, reroll, protect, gamble) and feel *alien targets* (species implicits, Stream bias, Skill Card Gl!tch, Squad role loadouts).

### 4.2 Soldering (vocabulary candidate)

**Soldering** = the act of installing / seating a **Module** into a gear socket (not a Skill). Fits Protocol “hardware” register without forcing PCB cosplay everywhere (IDEA-004: loose associations OK).

- Module = rollable inner system on gear (proc rules, Resonance hooks, Frame *modifiers* per DOC_v3 §11.9 Ancient Params spirit — without importing gem links).
- Soldering Agents (or a single **Solder Agent** + Module item) are the install/reroll tools.
- Wave 1 owns skill topology; Wave 2 only asserts: **skills ≠ gear modules**.

### 4.3 Gl!tch ≠ Vaal (fiction)

Operational rhyme allowed (irreversible, outcome table, locks further safe craft). Fiction must be Protocol:

- Skill Card **desyncs** from its Frame; polarity/quality/identity warps; “compiled wrong.”
- Visual language: `Gl!tch` orthography, error glyphs, not blood ritual.
- Gear “corruption” if needed: separate name (Surge / Fracture / Compile-fail) so Gl!tch stays Skill-scoped per CONTEXT + currency research §3.

## 5. Systems Angle

### 5.1 Functional barter + centralised vs disparate operable currencies

**Sold axiom (`POE_CURRENCY_ECONOMY_RESEARCH.md` §1):** no hard wallet cap; every crafting Agent is useful when consumed; trade primaries *emerge* from scarcity + aspirational sinks — do not hardcode “Agent X = money.”

| Layer | Role | Operable? |
|-------|------|-----------|
| **Crafting Agents** (few verbs) | Build power clock | Yes — primary |
| **NEM** | Vendor stabilizer, services, stash/MTX adjacency | Vendor-only; not trade primary |
| **Contracts** | Capture economy | Separate (DOC_v5 §41.3 — intentional isolation) |
| **CC** | Hub composed-craft fuel | Pace advanced ops; not trade king |
| **Cipher bases + Overrides / juice** | Session intensity clock | Separate from Forge Agents |
| **Stream materials** | Bias / recipe inputs | Optional; avoid potion treadmill |
| **Gold?** | Reopen | If added: do not make third Chaos; prefer cosmetic/regional/NPC |

**Centralised vs disparate:** Prefer **one Agent family** with shared UI grammar (tray, preview, lock toggle) and **separate drop pools** (gear Agents / creature Agents / Skill Agents) — DOC_v5 already sketches this. Do **not** merge Cipher juice into Scramble stock.

**Kirac-style buyouts:** Keep as a *diversifying avenue* (Network guide sells Cipher floor / Override packs / salvage Agents). Player should feel they *choose* whether to convert wealth → progression fuel. Ban only if it collapses the Cipher sustain design (Wave 3 owns that spine); Wave 2 says: **don’t pre-ban**.

### 5.2 Progression necessities — resource loops vs PoE; avoid busywork

| Necessity | PoE parallel | Mythoras shape |
|-----------|--------------|----------------|
| Identify / decrypt | Wisdom | Decrypt Agent abundant (DOC_v5 §48) |
| White → usable | Transmute / Alch | Elevate path; Exploit as Unique lottery |
| Volume reroll | Chaos | Scramble + (later) bench partial rerolls — see companion 3.29 signal |
| Targeted add | Exalt / essence | Inscribe + light ReAgent; Stream materials |
| Protect / lock | Metamods / fracture | Anchor + Imprint (pattern); **not** Splice |
| Safety net | — | Preservation (temper expiry); avoid ghost-roll flood day one |
| End Unique chase | Mirror / boss uniques | Temper Compile; true Uniques remain better than echoes |
| Deterministic floor | Chaos recipe / bench | Bench crafts + vendor Agent sinks + Network buyouts |

**Anti-busywork:** no multi-step potion crafting for baseline power; materials are *bias and endgame recipes*, not daily chores. Campaign craft = naked Agents in the field; hub composition unlocks later.

### 5.3 Gearing load (5 × ~10 ≈ 50)

DOC_v5 §40.2 already states the load and the mitigation:

1. **Empty early is correct** — campaign 3–5 slots; don’t drop Agents as if every slot needs Exotant.
2. **Role-distributed defenses** — offence creature invests Weapon/Crest; tank-tradeoff invests Armament/Helm; utility invests Belt/Talisman “good enough.”
3. **Pre-battle / pre-zone config** — Forge session before Cipher/zone; never mid-Turn-Program.
4. **Shared benches across Squad** — one Technician crafts; inventory is account/Technician-scoped, not five isolated economies.
5. **Modules concentrate depth** — better one deep Module on Crest than ten shallow crafts.
6. **Slot-count grill later** — CONTEXT’s 6-slot exploration remains valid pressure relief if 50 proves fatal in playtests.

### 5.4 Squad loot rules (single-player) vs Party (multiplayer)

| Mode | Rule of thumb |
|------|----------------|
| **Single-player Squad** | All drops → Technician inventory. No “need before greed” among creatures. Auto-assign suggestions OK; never auto-equip mid-run. |
| **Multiplayer Party** | Separate design: instance loot allocation, Party share, trade. Do **not** solve here. |
| **Monetization guard** | No free always-on self-hosted private server that erases online economy / Cipher Network / MTX stash value. Private/offline modes if any must be scoped so they don’t kill live monetization. |

### 5.5 Modules on gear vs skills on creature

- **Wave 1 owns** Skill Cards / Frame / constellation / Resonance-as-skill lever redesign.
- **Wave 2 asserts boundary:** gear sockets craft **Modules** (rollable inner systems); soldering vocabulary; DOC_v3 Ancient Params spirit (gear modifies Frame) without PoE socket bureaucracy.
- Frame Agents (Sync/Link/Hue…) may relocate or shrink under Wave 1 — treat DOC_v3 §11.7 as **historical inventory**, not MVP commitment.

## 6. Pitfalls

1. **MVP Agent taxonomy explosion** — DOC_v5 §§42–45 is a full endgame language. Shipping all verbs at once teaches nothing and burns sinks.
2. **Compile naming collision** — foundation rarity-up vs end Unique gamble will confuse players and docs forever.
3. **Gl!tch scope split-brain** — CONTEXT Skill Cards vs DOC_v5 gear Surge. Unresolved = wrong art, wrong sinks, wrong trade.
4. **Splice-shaped leftovers** — any “Unique mod fragment onto Rare” reopens the cancel. Vestigial echoes must stay weaker + non-fractureable.
5. **Fracture + lock after Unique power** — even without Splice, player-facing Fracture enables permanent T1 islands that trivialise Scramble. Gate hard or defer.
6. **Ghost-roll (AllFlame) as core** — multi-outcome preview is addictive and economy-warping; Intangibility-like counters are complex. Caution from `CURSE_OF_THE_ALLFLAME_ANALYSIS.md` — league experiment, not day-one foundation.
7. **50-slot craft anxiety** — if every drop screams “craft me,” players drown. Filter + empty-OK + role triage are mandatory UX, not polish.
8. **Collapsing clocks** — one Agent that both opens Ciphers and perfects gear (currency research “do not copy”).
9. **Potion / material busywork** — Stream materials as mandatory daily loop kills creature fantasy.
10. **Guided craft rails** — questlines that prescribe 12-step crafts kill community research; teach *verbs*, hide *weights*.
11. **Network Agents vs crafting Agents** — naming collision already flagged in plan; Wave 4 rename Network cast.
12. **Free self-host that kills monetization** — loot/economy design must assume live service constraints.
13. **Imprint triple meaning** — pattern-lock / snapshot / harness skill — always disambiguate.
14. **Affix grill delay** — designing Attribute-quad Agents before classification locks wastes work; keep verbs classification-agnostic.

## 7. Splice Cancel — Why, and What Remains

### Why cancelled (document permanently)

**Splice** = graft Unique-exclusive mod fragment onto a Rare (overwrite one affix). Even at 25–50% power:

1. **Chase collapse** — “good enough Unique-lite” on every Rare weapon removes the emotional Unique find.
2. **Fracture synergy catastrophe** — Fracture locks the spliced fragment → permanent Unique-flavoured island → recraft around it → **Unique power becomes a craftable base state**.
3. **Meta-lock explosion** — with Anchor/Imprint/Preservation, failure modes become retries; success becomes inevitable wealth flex.
4. **Trade toxicity** — “almost Spliced” / “pre-Fracture Splice” secondary markets skip intended gates.
5. **Systems debt** — every Unique mod needs a reduced fragment table forever.

**Cancel is final for this design wave.** Do not reintroduce under a new name without a grill that explicitly reopens this veto.

### Safer creative space that remains

| Space | Shape | Guardrail |
|-------|-------|-----------|
| **Exploit (early)** | Common/Uncommon → Unique gamble; Latent Weight favours empty slots | Floor via recipes; never guaranteed BiS |
| **Tempered Compile (end)** | Only Unstable Uniques (high Threat Examiner survival); Examiner-pool bonus; failure locks further mods; **endgame processed fuel** | Rename; no Fracture of Compile results into Rare bases |
| **Vestigial / Echo Modules** (PoE 3.29 Enshrouding *signal*, not copy) | Module carries *echo* of Unique fantasy at reduced power onto Module slot — not onto Rare prefix table | Echo Modules non-fractureable; true Unique still better |
| **Species Inscribe notables** | Creature-identity power without Unique-on-Rare | Species pool authorship |
| **Gl!tch on Skill Cards** | Identity gamble where it belongs | Separate art/sink from gear |
| **Bench partial rerolls** (3.29 Chaos bench *signal*) | Salvage “one god mod, rest trash” without Unique grafts | Costs Scramble-tier Agents; no lock of Unique fragments |

## 8. Creative Options — Enabling constructed steps without rails

Goal: players invent sequences; game never labels “Craft Guide Step 3.”

**Primitives that generate steps** (see companion doc for PoE evidence):

1. **Open slot vs full** — Inscribe vs Scramble tension.
2. **Protect then disrupt** — Anchor/Imprint before Scramble/Void.
3. **Category filters** — light DeAgent / Stream material bias (not Harvest-complete).
4. **Rarity gates** — Elevate / Ascend as thresholds, not spam.
5. **Bench as commit** — low-tier guaranteed mod as *temporary* scaffold (DOC_v5 multimod late).
6. **Partial reroll ops** — 3.29-style “reroll 1” / “reroll 3” as Scramble sinks that salvage near-hits.
7. **Exploit clean bases** — Latent Weight creates a *base economy* players invent around.
8. **Module soldering** — parallel craft track that doesn’t compete with prefix spam for attention.

**What not to ship as rails:** cookbook quests, forced metamod tutorials, UI that auto-suggests the “optimal 15-step craft.” Teach verbs in tooltips; let weights stay community-discovered (IDEA-018).

**Preservation vs ghost-roll:** one snapshot safety net (DOC_v5 Preservation) is enough for MVP. Multi-outcome ghost crafting stays post-MVP / league-shaped (AllFlame caution).
