# Cipher Network Progression Spine — Design

> **Status:** Design proposal (Wave 3). Not canon until grilled into GDD.  
> **Date:** 2026-07-19  
> **Scope:** Endgame progression spine — programme induction, first Cipher loop, board authorship / Profiles / factory specialization, Layer beat sheet, threat dials, NPC arcs, juice + Cipher Touch, MVP slice.  
> **Non-goals:** Locking Examiner/guide names; full Phrecia numeric recreation; AllFlame vessel/chart-voyage as day-one core; rewriting Motherboard Grid; copying Atlas juicing stack or Vaal beacon loop.

---

## 1. Executive verdict

Mythoras’s Cipher Network should be a **second game whose loop is configuring the first** (`POE_ENDGAME_RESEARCH.md` §9.8), expressed in Mythoras-native layers already named in GDD:

| Layer | Owns | Cadence |
| --- | --- | --- |
| **Cipher item** | Atomic run stake (mods, Layer, lives) | Per run |
| **Overrides** | Per-run juice | Per run |
| **Cipher Console / Board** | Persistent authored game-mode (Profiles, Phrecia commitment pieces) | Session → league-long |
| **Frontier** | Content amplify/block/warp + Cipher sustain | Meta points from Bonus Completion |
| **Motherboard Grid seam** | Rare BIOS/patch / Voidstone-like regional notable switches | Boss-gated global ratchets |

**Keep the Temple praise, not the Temple product.** Deterministic authorship + a small puzzle that deepens as pieces arrive (Minecraft Tech-it / temple-building *feel*) — **pieces are not rooms by default**. Steal Temple Console craft (instrument, diamond read, commit CTA) and reject beacon→crystal gather, opaque adjacency, and harsh random decay (`POE2_TEMPLE_RESEARCH.md` §4; IDEA-012/013).

**Entry fantasy:** campaign fingerprints a **pre-filled / semi-atlas** first board (IDEA-013). Completing early Ciphers **pays board growth and Profile unlocks**, not “farm fuel to paint blank tiles.”

**Fiction spine:** Hub (Compiler + Console) configures; Edge (regional frontiers) runs. Multi-region access is an **earned aperture** (IDEA-017). Light-touch governance narrates *who may open which edges* without becoming a bureaucracy sim. Threat is a **four-dial** player stake (Intensity / Severity / Threat + one non-pack-size fourth). Sticky global Cipher charges **and** per-run juice both stay (PLAN sold). Cipher fuel stays a **design tension** (mapping-for-progression vs trade-for-wealth), not a ban on Kirac-style buyouts.

**Narrative rulers of the Network:** legendary creatures (Nebby-like *redesign*, not Sun/Moon copy) share sovereignty with Protocol structure — Eldritch-equivalent bosses are one pillar, not the only cosmology.

## 3. Programme induction — working titles

After Regional Champion (or equivalent campaign close), the Technician is **inducted** into ongoing Network duty — not “unlocked a menu tab.”

### 3.1 Name candidates (working titles only — do not lock)

| Candidate | Fantasy | Notes |
| --- | --- | --- |
| **Front-Tier Excavation Charter** | Excavation into the front tier of the Network | Matches owner seed phrasing; archaeology + edge |
| **Edge Commission** | Champion commissioned to hold the frontier | Governance-light; hub/edge metaphor |
| **Compiler’s Charge** | Duty under the grand Compiler | Ties IDEA-008 Compiler hub |
| **Cipher Network Induction** | Plain, readable | Safe default; less evocative |
| **Surface Excavation Programme** | L1 as dig site into deeper Layers | Strong L1→L2 metaphor |
| **Protocol Edge Warrant** | Legal/structural aperture to open edges | Multi-region aperture fiction |
| **Network Charter (Provisional)** | Soft governance document | Light-touch bureaucracy |

**Recommendation for grill:** lead with **Front-Tier Excavation Charter** (flavour) + UI shorthand **Induction** / **Charter**. Keep “Cipher Network” as the system name; the programme is the *duty wrapper*.

### 3.2 Induction beat (fiction + systems)

1. Late campaign: L1 Ciphers already drop (`DOC_v5` §49.1) — foreshadow without endgame UI dump.  
2. Champion victory / Sequence close → **Interruption Zone Dialogue** (not a settings unlock): a guide figure appears in a zone the player already chose (IDEA-021).  
3. Escort / first dialogue pocket → Hub: Compiler + Cipher Console revealed as instrument.  
4. First board arrives **pre-seeded** from campaign fingerprints (routes, Sovereign fork outcomes, Remnant finds, mid-zone elite results — Examiner-class events if that title returns).  
5. First Cipher run completes → board gains first **authored piece** + Network Points path opens → programme “active.”

Governance stays light: Charter text explains *why* Champions open edges; multi-region apertures are earned milestones, not paperwork loops (IDEA-017).

## 5. First-Cipher loop anatomy

The first Cipher teaches the whole spine in one coherent loop. **Rooms are optional flavour later — not the completion grammar.**

### 5.1 What is “completion”?

**Recommended MVP completion = Network Activation**, not “clear every tile”:

| Step | Player action | System result |
| --- | --- | --- |
| **A. Select** | Choose a seeded Cipher node / consume an L1 Cipher item | Instance generates from campaign-known zone template + Network mods |
| **B. Stake** | Optional Threat dials + Overrides (light at L1) | Risk/reward priced upfront (`POE_ENDGAME` §9.3) |
| **C. Traverse** | Zone run (Squad lock, Load, Remnants) | Remix of known content under Cipher pressure |
| **D. Activate** | Defeat **Landmark** encounter (boss *or* activation ritual — both valid) | Cipher “completes”; lives unused ≠ required for completion |
| **E. Resolve** | Results panel | Rewards + board write-back |

**Boss vs activation:** L1 Landmark can be a **Circuit-echo boss** *or* a **Compiler Node activation** (hold site / compile sequence under pressure). Variety is good; one Landmark type per first Cipher is enough for MVP. Later Layers mix creature pinnacles, legendary creature seats, and structural activations.

**Layout:** Instance layout = remixed campaign zone template + Remnant fixtures — **not** a player-built room dungeon on first run. Board authorship affects *which content tags / global sticky mods / encounter weights* appear, not mandatory room placement.

**Creature generation:** Prefer **weighted remix of regional pools** + intel biases already in `DOC_v4` scouting — not a new spawn language. First Cipher may guarantee 1–2 “Network-touched” variants so Cipher Touch (§9) can be previewed lightly.

### 5.2 Reward → board building (the write-back)

Completing the first Cipher should feel like **the Network remembers you**:

| Reward class | Examples | Feeds |
| --- | --- | --- |
| **Sustain** | L1/L2 Cipher drops; boss +1 Layer chance (`DOC_v5` §49.2) | Climb fuel |
| **Economy** | Agents, materials, CC, Contracts | Forge / capture |
| **Meta points** | Network Points if Bonus rarity met (`DOC_v4` §35.4) | Frontier |
| **Board pieces** | 1–2 **Console Pieces** (paths, relays, amplifiers, locks — *not* rooms) | Console authorship |
| **Sticky charge (optional)** | First global Cipher charge slot unlock | Sticky juice (PLAN sold) |
| **Profile seed** | “Home Sector Profile” auto-created from campaign seed | Profiles (§6) |
| **Intel** | Endgame intel toward Network targeting (`DOC_v4` § scouting endgame) | Creature hunting |

**Write-back rule:** every early completion grants **at least one deterministic board or Profile ratchet** plus stochastic loot — SSF floor (IDEA-028). RNG modulates *which* piece; never *whether* the board grows after a successful first clear.

### 5.3 Cipher fuel tension (keep as tension)

Two legitimate avenues — do not collapse to one:

1. **Mapping-for-progression** — run Ciphers → drops + Bonus Completion → Frontier sustain → climb.  
2. **Trade-for-wealth / buyout** — guide vendor / gamble / Kirac-like Cipher sales / 3→1 combine — diversifies when drops dry (`PLAN` reopen: do not ban buyouts unexamined).

Early **gamble feature** (PoE-like; gold undecided) softens early sustain variance: e.g. gamble duplicate L1s or leftover Agents into a random L1–L2 Cipher or board piece. Exploit Agent family (IDEA-005) already models early gamble culture — Cipher gamble should rhyme, not duplicate gear-Unique gamble.

**Power** (IDEA-008 resource concept; name open) may meter Console commits / sticky charge refreshes — keep separate from crafting Agents and from Cipher items themselves (`RESEARCH_SYNTHESIS` economy note: Cipher sustain ≠ Forge wealth).

## 6. Board authorship / Profiles / factory specialization

### 6.1 What the board *is*

A **limited 2D shape-constrained grid** (Idol blocked-square lesson from IDEA-008 — shape constraint, not PoE Idol copy) where players place **Console Pieces** that:

- Amplify / block / warp encounter families (factory specialization — IDEA-029)  
- Contribute **sticky global Cipher mods** while a Profile is active  
- Unlock adjacency bonuses (small puzzle depth)  
- Do **not** require “rooms” — pieces can be relays, filters, pressure valves, Remnant anchors, Origin biases, Threat floor raisers, legendary-creature beacons, etc.

Temple adjacency *feel*: each new piece makes the small puzzle deeper. Anti-patterns: blank 81-tile anxiety, unexplained connectors, irreversible misplace without undo, decay that gut-punches authorship (`POE2_TEMPLE_RESEARCH.md` §4).

**Authored environment first:** Remnants and zone templates decorate instances; player pieces **bias and intensify**, not replace level design (IDEA-013).

### 6.2 Profiles = alternate boards / fresh game-mode starts

| Profile property | Design |
| --- | --- |
| **What** | A saved Console Board + sticky charge set + optional Frontier loadout link |
| **Fantasy** | Fresh game-mode start — “this Technician’s Breach-country vs boss-rush country” without a second character required |
| **Unlock** | Home Profile at Induction; additional Profiles via Layer milestones / Pinnacle / multi-region aperture |
| **Swap cost** | Cheap enough to experiment; sticky enough that Profile identity matters (Atlas loadout lesson — `ATLAS_TREE_RESEARCH.md` §1.4) |
| **Frontier link** | Optional: Profile can pin a Frontier preset; or Frontier stays global and Profiles only hold board+sticky — grill |

Profiles are how **factory specialization** stays plural: one board for capture-hunting, one for Agent wealth, one for pinnacle prep.

### 6.3 Phrecia Idol System (correct name) — high-commitment depth

**Role:** the **high-commitment specialization layer** that supplements Frontier (Atlas-like menu), matching owner correction in IDEA-008: Idol-like **supplements**, does not replace.

| Phase | Behaviour | Feel |
| --- | --- | --- |
| **Early drops** | Phrecia pieces drop **sealed / unmodifiable** | Found identity; high commitment; “this is what the Edge gave me” |
| **Mid** | Limited socketing into **Phrecia frames** on the Console (shape-constrained slots) | Tetris/alignment puzzle; blocked squares force builds |
| **Late** | **Recombinate / craft** toward extreme specialization | Chase craft; dangerous power; balance tension deferred (PLAN) |
| **Gateways** | Optional later — portals between commitment clusters | Expansion valve; not MVP |

**Heavy commitment design (now), balance (later):**

- Installing a Phrecia piece **consumes** it into the Profile (or locks it until expensive extract).  
- Early pieces are strong *and* narrow — they define a farm identity before the player can min-max.  
- Recombination unlocks only after Layer/Pinnacle gates so early game isn’t a craft spiral.  
- Frontier provides the **steady progression** Idol lacks (IDEA-008 NPC/Frontier function); Phrecia provides the **spikes**.

Do **not** recreate full PoE Phrecia numeric grids in MVP (`PLAN` non-goal). Ship: shape-constrained slots + sealed early drops + one recombination verb later.

### 6.4 Factory specialization (Factorio-like vector, Mythoras scope)

Long-term fantasy: the Console is a **game-mode factory** — amplify/block/warp encounter types until the endgame *is* the build (IDEA-029 / `POE_ENDGAME` §9.4).

**MVP factory = graph + weights**, not belt simulation:

1. Place pieces → see live “expected content mix” preview (structural transparency).  
2. Commit Profile → sticky mods apply to Cipher runs under that Profile.  
3. Frontier nodes multiply the same axes.  
4. Overrides spike a single run.

Full spatial factory sim stays distant (`RESEARCH_SYNTHESIS` “do not rush”).

### 6.5 Grid ↔ Network seam (mention only — do not rewrite Grid)

Motherboard Grid may later accept rare **BIOS / patch / Voidstone-like** variation switches that alter **regional notables** or Network-facing Directives (`PLAN` Wave 4). This document only asserts the seam:

- Grid = Technician combat/power authorship (CONTEXT #2).  
- Frontier + Board = content authorship.  
- Voidstone-like ratchets = few boss-gated **global** upgrades to farming (Watchstones→Voidstones lesson — few monumental trophies beat many fiddly regional dials).

## 7. Layer beat sheet

Aligned to `DOC_v4` / `DOC_v5` Layers; leaves expansion room; salt timing per owner ask.

| Layer | Fiction beat | Systems beat | Cast / lore |
| --- | --- | --- | --- |
| **L1 — Surface Network** | Standard progression; Induction; home sector excavation | Learn Cipher item, Console, Bonus Completion; light Threat dials; first board pieces | Guide / Quartermaster-type; interruption onboarding |
| **L2 — Outer Cipher** | **Fracture rumble at the frontier** — edges desync; Protocol “bleed” echoes campaign Seren warning (`DOC_v4` §36) | Full mod pool; Overrides matter; second Profile candidate; Frontier sustain nodes priority | **New NPC arrives** (~L2) — Herald / interrupting voice; first legendary-creature whisper |
| **L3 — Deep Cipher** | Builds required (`DOC_v5` L3 checkpoint); **salt frontier begins** (see recommendation) | Hostile sticky options; Phrecia frames open; Standard Pinnacle materials appear late L3 | Remix curriculum starts; odd characters; lore-interested dialogue density up |
| **L4 — Volatile Reaches** | Salt frontier **mature** / edge war; multi-region apertures climax | Volatile lives option; Apex Pinnacle gating; extreme Phrecia craft | Remixed encounters + odd characters as plot carriers; legendary creature **seat** contests |
| **L5 — Reserved / Void** | Void / infinite mapping horizon | Expansion: infinite anomaly chart, void Profiles, seasonal fold-in | New cosmology cast; do not overload MVP |

### 7.1 Salt-frontier layer recommendation

**Recommend: salt frontier opens at late L3, matures through L4; L5 holds void/infinite.**

| Option | Pros | Cons |
| --- | --- | --- |
| Salt at L3 | Matches “builds required” difficulty spike; gives L4 exclusive *escalation* of salt rather than introducing two big ideas at once | Risk of L3 content budget bloat |
| Salt at L4 only | Cleaner L3 = “just get good at Network” | Salt feels bolted onto already-volatile Layer; less room before void |
| **Hybrid (recommended)** | **L3:** first salt *sites* / fracture NPCs / one salt landmark type. **L4:** salt as regional weather + Phrecia salt pieces. **L5:** void mapping | Needs clear teaching so salt ≠ “just harder mods” |

Leave room for expansion: salt is a **biome/pressure identity**, not a full league stuffed into MVP.

### 7.2 Escalation grammar (every Layer)

Known loop → interruption (zone dialogue) → guided remix → named landmark/pinnacle → open horizon (IDEA-020). Failure mode to avoid: Sirus-like disconnected late boss (`POE_ENDGAME` §9.5).

## 8. Threat dials

Threat Attunement remains the mechanical dial; naming reopen (IDEA-015 / PLAN). Expose **four independent stakes** — three named by owner + one invented non-pack-size axis.

| Dial | What it scales | Reward hook | Notes |
| --- | --- | --- | --- |
| **Creature Intensity** | Pack/elite *quality* — AI aggression, elite mod rate, Load pressure | Quantity of mid-tier loot / Contracts | “How hard are the creatures,” not pack *count* |
| **Severity** | Ailment severity floors, boss phase thresholds, Apex gates (preserve 0–150%+ meaning) | Crafting materials / ailment-relevant drops | Clinical/diagnostic register |
| **Threat** | Short umbrella or encounter *attention* — aggro breadth, objective timers, interruption rate | Bonus Completion leniency / Network Point mul | Watch collision with any aggro table naming |
| **Fourth — Sync Contagion** *(working name)* | How much Cipher Touch / ghosted mods / sticky charges **spread** across the instance | Cipher Touch harvest rate; rare board pieces; Override fragments | Explicitly **not** pack size. Alternatives: **Compile Pressure**, **Remnant Saturation**, **Edge Drift** |

**Design rules:**

- All dials optional; defaults teachable in Interruption Zone Dialogue.  
- Breakpoints public in UI (IDEA-018).  
- Dials compose with Cipher rarity/Layer — Layer sets ceiling; dials spend player courage inside it.  
- Do not add a fifth “pack size” copy; density fantasies go through Intensity + Contagion, not monster count stacks (anti–Atlas juicing copy).

## 9. Juice & Cipher Touch

### 9.1 Two juice clocks (keep both)

| Clock | Mythoras surface | Cadence |
| --- | --- | --- |
| **Sticky global** | Console Profile charges / global Cipher mods from board + Phrecia | Many runs; spent/refreshed on Hub time |
| **Per-run** | Overrides on the Cipher item; Warbanner opt-in; Threat dials | This Cipher only |

Matches Atlas tree vs scarabs split without importing scarab shopping lists (`ATLAS_TREE_RESEARCH.md` §2.2). Sextant-style “pay juice on filler” anti-pattern: sticky charges should not auto-burn on throwaway Ciphers — player chooses Profile / charge engagement.

### 9.2 Cipher Touch (Tormented Spirit analogue — redesign)

**Cipher Touch** = ghosted Network modifiers that can inhabit **capturable creatures** and **pinnacle/landmark entities**.

| Property | Proposal |
| --- | --- |
| **Appearance** | Mid-run interruption or Landmark aura — visible ghost/compile VFX |
| **Player agency** | Choose to engage / capture-touched / banish / harvest |
| **On capturable creatures** | Touch becomes a **post-capture enrichment hook** (ties Enrichment enAgents late — `DOC_v5`) or a temporary run buff if released |
| **On pinnacles** | Touch stacks into invitation materials / remix keys (Maven-like curriculum without copying Maven) |
| **Harvest** | Yields Override fragments, sticky charge fuel, or sealed Phrecia crumbs |
| **Sync Contagion dial** | Raises Touch spawn and spread |

Not a mandatory juicing tax; a readable detour (AllFlame Anomaly lesson — free variety without tree tax — park full Anomaly board for later).

### 9.3 Sticky vs board vs Override — ownership

- Board/Phrecia → **what content tends to appear**.  
- Sticky charges → **persistent Network weather** for this Profile.  
- Overrides → **tonight’s spike**.  
- Cipher Touch → **diegetic inhabiting juice** on creatures/bosses.

## 14. Designer / Systems / Pitfalls / Creative

### 14.1 Designer

The emotional promise is **authorship without homework**. The Technician should feel inducted into a living Network that already bears their campaign fingerprint, then gradually *author the game they want to play* — not farm crystals to paint a blank temple, not spreadsheet an Atlas juicing ritual. Champion duty gives fiction weight; Profiles give plural identity; legendary creatures give the Network a pulse beyond abstract bosses.

Tone stays multi-register (CONTEXT #1): Hub can be warm and invitational; Edge salt can be harsh; void can be quiet and infinite — do not paint endgame as permanent grimdark.

### 14.2 Systems

Three authorship planes, clear clocks:

```
Campaign seed → Home Profile board
     ↓
Cipher run (item + dials + Overrides + Touch)
     ↓
Rewards → sustain + Network Points + Console pieces + Phrecia sealed
     ↓
Frontier allocation (steady) + Phrecia install (spike) + sticky charges
     ↓
Richer Cipher runs / apertures / pinnacles
```

Ownership preserved: creatures still own skills; Technician owns Grid + Command Deck + Network configuration. Board never becomes a second Skill Frame.

### 14.3 Pitfalls

| Pitfall | Mitigation |
| --- | --- |
| Blank-board anxiety | Pre-seed; soft unlock pieces; undo |
| Sustain stall | Boss drop + 3→1 + buyout/gamble; Frontier sustain first |
| Juice choreography bloat | Cap sticky slots; small Override set; no sextant ritual |
| Pack-size arms race | Fourth dial ≠ density-by-count; Intensity ≠ pack size |
| Agent word collision | Cadre rename everywhere |
| Examiner lock creep | Candidate pool only |
| MVP overload (AllFlame, full Phrecia, void, Ascension) | Hard defer list §12 |
| Orphan currencies | Every reward maps to named sink |
| Regional Frontier fragmentation | Prefer global Frontier; multi-region = aperture, not 8 trees (`ATLAS_TREE` regional failure) |
| Decay gut-punch | No random board wipe; if pruning exists, player-authored or soft |
| Sirus disconnect | Layer beat sheet + remix curriculum before seats |
| Option overload on 3v3 | Factory configures content, not more Field actions (IDEA-030) |

### 14.4 Creative

- **CloudFront-at-edge** as diegetic joke for engineers and fantasy metaphor for everyone: Hub compiles policy; Edges serve encounters.  
- **Charter document** as a diegetic UI page that updates with apertures — light governance that players *want* to read.  
- **Legendary creature as sector CDN** — when it sleeps, that Edge’s Ciphers quiet; when it stirs, Contagion rises.  
- **Salt** as white crystalline Protocol corrosion — beautiful and hostile; Remnants frost over; dialogue gets quieter and stranger.  
- **Odd characters** at salt/void: failed Champions still running obsolete Profiles; Cadre who only speak in compile errors; a creature that collects Resolutions.  
- **Wage of War** (IDEA-016) as a possible sticky-charge Unique later — not MVP.  
- Console commit SFX: a single heavy *clack* — the Temple quality bar in audio.
