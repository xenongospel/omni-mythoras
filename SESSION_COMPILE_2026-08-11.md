## 2. Skills system — settled directions

### 2.1 Soft-fail / match bonus
- **Mismatch:** works at **base standard**.
- **Match:** apply bonus(es) — prefer **skill-specific** bonus; optional **generic** bonus (pseudo-quality, **not** named Quality).
- Players should enjoy “generic + this skill” feel without PoE Quality vocabulary.

### 2.2 Container & presentation
- Creature remains skill host (CONTEXT #9).
- **Reconfigure** Frame / anchors / satellites — current model “isn’t doing it.”
- **Do not keep constellation shape** for skills.
- **Keep Skill Cards** for now (physical metaphor still OK for MVP).
- MVP readability: **sockets in a horizontal line** (PoE2-like temporary scaffold) **and/or** Mercenary-window dossier (gear up top; skills listed with **horizontal support rows**). Prefer Mercenary template for “inspect creature” MVP.
- Later expansion: special skill holder / skill-card trees bridging Last Epoch–style skill investment (temp or permanent depending on expansion success).

### 2.3 Free-flow sockets (intent)
- Want a **generic socket** that can hold active **or** utility **or** other classified skills — free-flowing settled configuration.
- Prefer PoE1-like flexibility of what sits where, without assuming gear sockets.
- Command Deck / Warbanner / Inscriptions: **park** this session — possible later subcategory / lane (packs?).

### 2.4 Avenues / classifications
- Active + Support remain primary.
- **Third avenue** important — possibly optional 3rd / 4th, or umbrella for subclasses:
  - Protocol (candidate subclass)
  - Persistent / field / trigger (umbrella candidates)
  - Modules, rights, trigger skills, field-effect skills, persistent/reserve skills, etc.
- Could be **4 major avenues + 2 lesser** — grill later.
- **Accelerators** as a class of supports that accentuate builds; domain-flavoured effects (e.g. Arcane-like “increases/decreases to spell damage affect X”) — **GGG-inspired, Mythoras-native wording**, not copy.

### 2.5 Support power philosophy
- Hybrid support power: **damage scalers + mechanical behaviour changes**, expressed in classifications — not one flat “More” channel.
- Study PoE1 3–4 damage-support architecture (crit multi, concentrated effect, echo/return layers) **and** PoE2’s behaviour/ailment bridging — unpack without copying architecture blindly.
- **Composable verbs** for skill construction — Mythoras-native version.
- Optional metaphor: **build the skill like a computer** — core tendencies for campaign onboarding; more component variants late when farm density rises.

### 2.6 Links / jewellers / depth
- If links exist: want **link RNG** requiring **more than one** non-deterministic application (not PoE2 one-shot tax only).
- **Jewellers (or analogue) needed for endgame** so early-caught creatures stay viable.
- Species topology may “root” some capacity by creature.
- **Third deep skill:** unknown if wanted. Working floor: **Technician Level** gates when third-deep becomes visible/linkable; **species topology + Agents** refine. Combination of both.
- **Question the six-support skill:** Why copy PoE’s 6-link loop? Depth budget is open — do not re-engineer 6-link by default.

### 2.7 Numbers / generation / early vs late catch
- Support counts, breakpoints, campaign→endgame maps: **all reopen**. Wave 1’s 3-breakpoint hybrid map is not locked.
- Need a clear **generation plan** for creature-attached skill configuration + progression.
- Creature Level may matter more if scaling touches gear + skills over time.
- **Early vs late catch:**
  - Compress base species power gaps (Pokémon late-species problem).
  - Differentiate via implicits, species supports, gear, depth systems Pokémon lacks.
  - **No EV-like grind** — avoid like the plague.
  - Hold both fantasies: keep-and-raise early creature **and** collect/upgrade into later finds (starter-system lesson worth studying).
  - **Natured / pre-catch moves** with bonus → collecting incentive for specific mugs.
  - Mercenary window as reverse-engineering template for creature inspect / recruit fantasy.

### 2.8 Instrument / storage
- **Tuning fork** remains Pokéball-analogue reference (Runeseeker Call Unique).
- Layer TBD: storage / out-of-world existence imagery that aids the fork.
- Idea: creatures as **runes** seated in fork “sockets” (visual rhyme with Unique + inventory sockets).
- Speculative: Gl!tch/corrupt fork → **6th party member** (symbolic vs Pokémon 6; narrative funny; may never ship).
- Portable **soldering-iron** instrument for field operations — idea vector.

### 2.9 Romance / fantasy of play
- More than PoE skill-gem romance.
- Keep Pokémon joys: team configuration vs challenge, doubles/VGC-style skill combination, intelligent switches, forcing advantages within creature limits.
- Theorycraft Surfers + **progression chase emotion** + **readable scarcity** remain design pillars.
- Tabula / temporary perfect-link uniques: good progression accelerators (damage from links > defence loss as classic opportunity cost).
- PoE2 triggers: interesting later; different representation; not day-one copy of “when damage taken” costs.

### 2.10 Grid expansion (parked)
- Skills socketed into Motherboard with Grid-sourced scaling (no supports) — expansion only.

## 6. Lessons learned (this research arc)

1. **GDD-first cross-check prevents orphan “discoveries”** (colour-as-bonus already in DOC_v3; AllFlame rediscovered it).
2. **Vocabulary collisions kill clarity** — Resonance overloaded; Frequency/Alpha–Delta disliked; Gl!tch scope split CONTEXT vs DOC_v5.
3. **PoE facts drift** — Wave 1 understated PoE2 links / exclusivity changes; always date-check sequels.
4. **Do not copy 6-link by reflex** — ask what depth budget Mythoras actually needs.
5. **Creature romance ≠ gem romance** — team tactics, switches, early-raise fantasy matter as much as support architecture.
6. **Early-catch viability needs explicit systems** (jewellers, compressed bases, species depth) — not EV grind.
7. **MVP UI should be legible first** — Mercenary horizontal supports beat constellation art for now.
8. **Cipher spine is loadable** — Threat Dials + factory/board authorship + salt-frontier beat are the keepers; voyage cadence is a rhythm spice.
9. **Crafting foundation is on rails** — Agents + emergent steps + thin MVP verbs; Fracture/Echo/buyouts later.
10. **Multi-path endgame outputs** (bee farm lesson) is a standing design principle for exclusive vs shared rewards.
