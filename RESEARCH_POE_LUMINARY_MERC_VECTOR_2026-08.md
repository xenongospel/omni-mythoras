- Appear from Act 3+; duel; wager gold on a carried item; win → temporary ally for N areas.
- Warrant / rematch / trade patterns; Atlas + Trarthan Scarabs for targeting.

### Luminary (Scion Ascendancy)

- Permanently hire Mercenaries (commonly described as up to **3** with **1 active / 2 reserve** — confirm against live patch notes when implementing anything).
- Gear the merc; Unique gear gated by Ascendancy nodes (e.g. Legendary Arms / item-slot unlocks).
- Link / aura / bodyguard synergy between player and merc.
- **Ascendancy tree options determine how you play with mercs** — commander fantasy as class identity.

**Portable principle (not a copy):**  
**Player-identity layer (Foundation / Ascendancy-analogue) that rewrites Squad rules globally** — hire permanence, gear rights, link economy, defensive sharing — while creatures remain locally configurable. Mythoras already has Technician-global Motherboard Grid + creature-local skills; Luminary is a reminder that *some* squad-management power can live on the Technician identity track.

**Do not import:** Scion as class, merc duel wager loop as default content, “1 active + 2 reserve human mercs” as Squad size (Mythoras Squad size already locked elsewhere).

## Ascendancy concept origin (GGG — brief answer)

**Question:** Did GGG cite a specific external inspiration for Ascendancies?

**Answer from contemporary coverage (2015–2016 Ascendancy expansion):**

- **Design problem stated to press:** classes felt indistinct later because the shared passive tree lets you wander far from your starting identity; Ascendancy subclasses make the initial class choice matter again by adding a small specialized tree at the center ([PCWorld preview quoting GGG](https://www.pcworld.com/article/424525/path-of-exiles-free-new-ascendancy-expansion-looks-roguelike-like.html)).
- **Delivery vehicle:** Trials of Ascendancy + Lord’s Labyrinth (daily shared layout, trap teaching → Labyrinth) — Chris Wilson interviews emphasize Labyrinth/traps/Izaro fantasy and F2P goodwill more than a named “we stole Ascendancies from X” ([Deepest Dream Wilson interview](https://deepestdream.com/exclusive-path-of-exile-ascendancy-interview-with-chris-wilson/); [PCGamesN](https://www.pcgamesn.com/path-of-exile/path-of-exile-ascendancy-introduces-tricks-traps-and-emperors)).
- **No strong first-party quote found** in this pass that names a single external game as *the* Ascendancy inspiration (unlike passive tree ↔ Final Fantasy sphere-grid lore that the community and GGG have discussed more openly over years). Treat Ascendancy’s origin as: **internal response to class-identity dilution + Labyrinth content fantasy**, not a documented one-to-one remake of another title’s subclass system.

**Mythoras takeaway:** Ascendancy = *re-specialize the player identity after the open tree dilutes it*. For Mythoras, ask whether Technician Foundations / Principals need that “matter again” beat — separate from Luminary’s companion-commander fantasy.
