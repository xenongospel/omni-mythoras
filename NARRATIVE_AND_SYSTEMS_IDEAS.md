## 1. Trailer craft lessons — The Line Animation reel

**Source clip:** ~49s vertical (9:16) process reel — not a finished story trailer, but a **pipeline-as-spectacle** marketing piece. Whisper transcript is near-empty (“Welcome to the Smúsica / I'm out”) — craft lessons come from picture, not VO.

**Reel grammar observed (from frames):**

| Pipeline beat | What the reel shows | Mythoras marketing takeaway |
| --- | --- | --- |
| ANIMATIC | High-contrast silhouette, scale, impact shapes first | Sell **stakes and silhouette** before polish; one readable pose per beat |
| ROUGH | Volume, motion trails, smears, foreshortening | Motion readability > detail; pink/orange trails as temporary “energy vectors” |
| TIE DOWN | Clean line + technical markers (FX node circles) | Protocol fantasy can literally show **compile markers / frame nodes** as diegetic craft |
| CLEAN & COLOUR | Flat colour, strong character read on empty field | Creature + Technician must read as brand silhouettes without FX |
| 2D FX | Isolated jagged energy / rings / debris on black | FX as a **named craft layer** — Resonance, Stream signatures, Impact frames |
| COMPOSITION | Rim light, grade, depth, environment integration | Comp is where tone lives (CONTEXT Critical Correction #1: register shifts with biome/stakes) |

**Motion / composition patterns worth stealing:**

1. **Scale contrast as relationship storytelling** — tiny hat-rabbit framed by rearing tiger-guardians (frame-within-frame arch). Mythoras: companion / vessel / contracted creature vs. zone threat, not “trainer + mascot in equal framing.”
2. **Process split-screen as trust marketing** — showing ANIMATIC→COMP proves intentional craft. For a creature battler with deep systems, process reels can sell *depth without dumping UI*.
3. **Impact frames + isolated FX passes** — jagged cyan bursts, elliptical energy rings, motion circles. Map visually to Stream Signatures / Resonance stack pops / Warbanner deploy — without inventing new mechanics.
4. **Intimate bond close-up** — character face + mask/creature artifact, knowing smirk. Directly supports wand/bond/pact marketing (Technician–creature intimacy, not Pokémon “catch and forget”).
5. **Vertical cinematic escalation in ~50s** — calm temple → chase → explosion → staff action → glide over neon canyon → mask intimacy. Expansion-trailer cadence in short form: **establish → pursue → rupture → power → voyage → bond**.
6. **Tone dial within one reel** — cool blue night temple, mustard clean plate, warm red mask finale. Reinforces multi-register world (IDEA-009 / CONTEXT #1), not single grimdark brand.

**What not to copy blindly:** Pure BTS process reels assume an already-famous IP. Mythoras marketing still needs a **story-forward** cut that uses these craft lessons *inside* narrative beats, not only as studio flex.

## 6. Skill Frame → creature-local constellation / skill network — EXPLORATORY ONLY

### What is locked today (do not treat rethink as decided)

From CONTEXT:

- Skill Cards, Skill Frame, Support links, Breakthrough, Mana = **creature-local**.  
- Motherboard Grid = **Technician-global** (+ slot-local subroutes).  
- Skill Frame = intrinsic configuration network: **anchor nodes** (Skill Cards) + **satellite nodes** (Support Cards) + **species-specific topology**.  
- Resonance = **two-tier locked** (Tier 1 Stream Resonance baseline; Tier 2 named deep mechanics via Grid investment). Per-Stream stacks, not a free-form STAB return.  
- **STAB removed**; Stream Alignment is the conditional match bonus.

### Owner exploratory ask

Rethink Skill Frame presentation/topology toward a **creature-local constellation / skill network**; consider Resonance / Alignment side effects; explore **gear-tie alternatives that are NOT PoE sockets**; note that **PoE2 already took socket-colour compensatory buffs**, so Mythoras must differentiate.

### Explicit tensions to flag (not resolve)

| Exploratory impulse | Locked canon it may scrape |
| --- | --- |
| “Constellation” as Technician-wide skill sky | Ownership #9 / #2 — skills stay creature-local; Grid stays global |
| Returning STAB-like always-on type bonus | STAB removed; Alignment is conditional |
| Tying Resonance stacks to Frame sockets | Resonance Tier 2 is **Grid-investment** gated, Stream-scoped |
| Gear that “socket-links” skills like PoE gems | Forbidden copy path; also risks turning gear into a second Frame |
| Compensatory buffs for “wrong colour / wrong link” | PoE2 already owns that compensatory design — Mythoras should **re-modify differently** |
| Lattice / synapse metaphors | IDEA-004 naming directive — avoid LLM-default “lattice”; physical imaginability required |

### Safer exploration lanes (still not decided)

1. **Visual constellation only** — Frame topology already species-specific; present anchors/satellites as a creature-local star map without changing ownership.  
2. **Gear as constellation *modifiers*, not sockets** — e.g. Imprint Interface / Symbiotic Slot warps Frame edge weights, unlocks Breakthrough-adjacent routes, or changes Support satellite capacity — not gem-link colours.  
3. **Side effects via Alignment + Tier 1 Resonance visibility** — show stacking Stream Resonance and Alignment bonuses as constellation “flare” VFX (trailer FX lesson), without new math axes.  
4. **Species topology as the differentiator** — depth lives in authored creature graphs (Principal / Pinnacle Evolution adjacency), not in socket-colour puzzles.

**Status:** Parked for a dedicated grill. Do **not** rewrite CONTEXT.md from this note.

→ Logged: **IDEA-024**

## 10. SSF-first + nested goals + player-dialed difficulty

**Owner stack (aligns hard with POE_ENDGAME §9.1–9.3, 9.6–9.7):**
